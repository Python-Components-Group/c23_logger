# c23_logger

[![License](https://img.shields.io/badge/license-Custom--SA-%231b25e5)](https://raw.githubusercontent.com/Python-Components-Group/c23_logger/refs/heads/main/LICENSE)

A Python component that provides logging services for any Python software process (mainly used in [GenTestsAILib](https://github.com/codesavant23/gentestsai/))

## How to get the component

### Latest stable release

You can find the binaries of the component in the [release](https://github.com/Python-Components-Group/c23_logger/releases) section of this repository

### Latest build

#### Installation

  ```python
  pip install git+https://github.com/Python-Components-Group/c23_logger
  ```

#### Update

  ```python
  pip install git+https://github.com/Python-Components-Group/c23_logger --upgrade
  ```
